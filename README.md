# StudyBudget：留學生記帳

給留學生用的離線記帳 PWA，支援多幣別帳戶、跨幣別轉帳，以及外幣刷卡的原幣金額記錄。資料只存在瀏覽器的 IndexedDB，不會上傳。

> 目前是 v2 重建版。v1 的程式碼已全部移除；舊版的歷史仍保留在 git 紀錄中。

## 目前功能

- **交易**：新增、編輯、刪除支出／收入／退款／轉帳；可依月份瀏覽，依帳戶、類型篩選；搜尋商家、備註或分類名稱時會找遍所有月份，並加總搜尋結果。
- **退款與分帳**：退貨退款、朋友還你代墊的錢記成「退款」，會從該分類的支出扣掉，不會被當成收入。
- **固定收支**：房租、訂閱、每月生活費勾選「每月固定」後，每月到期時會在交易頁提醒，按「記上」才記錄，也可以略過；錯過的月份會依序補上。可在設定頁停止。
- **快速記帳**：帳戶以按鈕切換並標示幣別，預設為近 30 天最常用的帳戶；儲存鈕固定在底部，可「再記一筆」連續輸入；有輸入內容時關閉會先確認。
- **跨幣別轉帳**：轉出和到帳金額分開記，並顯示換算出的匯率；可填手續費，會另記一筆「手續費」支出。
- **外幣刷卡**：金額旁的幣別可以切換，直接輸入 ¥5,000；App 依匯率和卡片的海外交易手續費（例如 1.5%）估算扣款，帳單出來後可改成實際金額。手續費併在同一筆，但概況會把它算進「手續費」分類，看得出每月付了多少。每個帳戶會記住上次用的幣別。
- **帳戶**：填目前餘額（信用卡填目前欠款），之後可直接改餘額來校正；可設定海外交易手續費；新帳戶依裝置時區預選當地幣別；已有交易的帳戶可以封存，但不能刪除或更改幣別。餘額一律由交易計算。
- **分類**：可新增、改名、換圖示，或隱藏用不到的分類。
- **本月概況**：本月支出、收入、結餘換算成主要幣別；每月預算（可用任何幣別，例如 ¥80,000）顯示已花、還剩、每天平均可花多少；分類排行，點進去看該分類的交易；帳戶合計。
- **匯率**：每天自動下載（[currency-api](https://github.com/fawazahmed0/exchange-api)，含台幣，不需金鑰），存在裝置上，離線也能換算；缺匯率的幣別會標示出來，不會被當成主要幣別加總。
- **備份與還原**：下載 JSON 備份檔（手機可直接分享到雲端硬碟）；還原前先預覽內容，還原後可立即復原；超過 7 天的資料沒備份時會提醒；可要求瀏覽器永久儲存資料。
- **匯出 CSV**：所有交易匯出成試算表檔（Excel 開啟中文不會亂碼），欄位名稱跟著介面語言。
- **新手引導**：第一次開啟時有三步設定：選當地和家鄉的幣別、勾選常見帳戶（現金、當地銀行、台灣的銀行和信用卡，信用卡預填 1.5% 海外手續費），並說明資料只存在手機、要記得備份。換手機的人可以直接從備份還原。
- **使用說明**：右上角的「?」開啟使用說明，用留學生常見情況說明怎麼記：在國外刷卡、朋友還錢、匯款、房租等。
- **介面**：繁體中文／英文；手機底部導覽，桌面上方導覽；可安裝成 App 並離線使用。

## 開發

需求：Node.js 20.19 以上。

```bash
npm install
npm run dev       # 開發伺服器
npm test          # Vitest（核心邏輯 + 畫面測試）
npm run lint
npm run build     # 型別檢查 + 正式建置
```

## 專案結構

```
src/
├── core/        記帳核心：資料模型、IndexedDB（Dexie）、驗證、報表、備份。不依賴 UI。
├── app/         App 外框：版面、資料庫 Provider
├── features/    功能頁面（transactions、accounts、overview、recurring、backup、settings、rates、onboarding）
├── ui/          共用元件與格式化工具
├── locales/     zh-TW／en-US 翻譯
└── test/        測試輔助（fake-indexeddb 測試資料庫、renderApp）
```

資料模型的設計（整數金額、由交易推算餘額、轉帳雙分錄、匯率換算）寫在 [`src/core/README.md`](src/core/README.md)。

## 部署

使用 Vercel 等靜態網站主機即可：建置指令 `npm run build`，輸出目錄 `dist`。`vercel.json` 會把所有路徑導回 `index.html`，讓 `/transactions` 這類網址重新整理時也能正常開啟。
